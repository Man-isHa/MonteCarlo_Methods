Learning values from experience on a slippery frozen lake

  1. Model known: policy iteration
  2. Model hidden: first-visit Monte Carlo
  3. Model hidden: every-visit Monte Carlo

The slippery lake 5 × 5

Action then click any ice cell
\[P(s'\mid s,a)=\begin{cases}0.8 & \text{intended direction}\\ 0.1 & \text{each perpendicular direction}\end{cases}\]

Sliding into a wall keeps you where you are.

\[R=\begin{cases}+1 & \text{reach } G\\ -1 & \text{fall into } H\\ \phantom{+}0 & \text{otherwise}\end{cases}\qquad \gamma=0.9\]

The episode ends in a hole \(H\) or at the goal \(G\).

Policy iteration model known

1. Policy evaluation

\[V^{\pi}(s)=\sum_{s'}P(s'\mid s,\pi(s))\big[R(s')+\gamma V^{\pi}(s')\big]\]

2. Policy improvement

\[\pi'(s)=\arg\max_{a}\sum_{s'}P(s'\mid s,a)\big[R(s')+\gamma V^{\pi}(s')\big]\]

3. Repeat until \(\pi'=\pi\)

Optimal policy and values

\[\pi^*(s)\ \text{(arrows)},\qquad V^*(s)\ \text{(numbers)}\]
Every number here used \(P\) and \(R\).
What if we don't know them?

Starting fresh: the model is hidden

Arrows: a fixed, hand-written policy \(\pi\) (not optimal)

\[P(s'\mid s,a)=\ ?\qquad R=\ ?\]

We can only act and observe:

\[S_0,\ A_0,\ R_1,\ S_1,\ A_1,\ R_2,\ \dots,\ S_T\]

Goal: evaluate the policy \(\pi\)

\[V^{\pi}(s)=\mathbb{E}_{\pi}\big[\,G_t\mid S_t=s\,\big]\]
\[G_t=R_{t+1}+\gamma R_{t+2}+\gamma^{2}R_{t+3}+\cdots\]
Monte Carlo: replace the expectation with an average of returns we actually observe.

Episode 1: follow \(\pi\) and record

At each step take \(A_t=\pi(S_t)\); the ice decides where you land.

Small orange arrow = the direction you actually slid. Demo episodes are sampled until one revisits a state.

Empirical estimates from episode 1 first visit

\[G_t=R_{t+1}+\gamma\,G_{t+1},\qquad G_T=0\]
\[V(s)=G_t\ \ \text{at the first } t \text{ with } S_t=s,\qquad N(s)=1\]

Episode 2: same policy \(\pi\)

A new run from the start. Same \(\pi\), different luck on the ice.

First-visit Monte Carlo update

Values after episodes 1 and 2

\[N(s)\leftarrow N(s)+1,\qquad V(s)\leftarrow V(s)+\frac{1}{N(s)}\big(G_t-V(s)\big)\]

only at the first \(t\) in the episode with \(S_t=s\)

Repeat for many episodes

Each estimate is a running average of first-visit returns; the curves settle as \(N(s)\) grows.

Start afresh: every-visit Monte Carlo

Reset \(V(s)=0,\ N(s)=0\). Same \(\pi\). This time every visit to \(s\) counts.

\[V(s)=\frac{1}{N(s)}\sum_{t\,:\,S_t=s}G_t\]

Episode 2 and the every-visit update

\[V(s)\leftarrow V(s)+\frac{1}{N(s)}\big(G_t-V(s)\big)\quad\text{for every } t \text{ with } S_t=s\]

Repeat and compare with \(V^{\pi}\) every visit

First visit vs every visit, same episodes

Both learn \(V^{\pi}\) from samples alone: no \(P\), no \(R\).

First visit: one return per state per episode, unbiased.

Every visit: more returns per episode, slightly biased, still converges to \(V^{\pi}\).
